# evaluating_soft_block — project stage instructions

When evaluating whether work can be picked up, search around for any indications to relevant decisions.
Consider reversibility - is the wrong decision here going to cause major problems down the line? If so wait for more information. If not we can probably get started. 
Similarly, consider how unblocking this work is. If there's already a ton of unblocked work then the marginal gain on unblocking this new bit is low.
